# 把你砌进神像里

一个可驻留在系统托盘的 Windows 可视化工具。它仅使用普通输入模拟，不会读取或修改游戏内存，也不会注入游戏进程。

主界面采用正方形纯色布局；程序文件、窗口标题栏和系统托盘统一使用雷电将军头像图标。

## 可靠输入模式

- 原神/Unity 不接收普通的失焦窗口键盘消息，因此“检测到游戏窗口”不等于游戏会响应后台按键。
- 启动任一功能时，助手会自动恢复并切换到原神，再使用 Windows `SendInput` 发送按键和点击。
- 原神失去前台焦点后，助手会暂停输入并释放长按键；重新切回原神时继续当前功能。
- 看视频时可使用浏览器“画中画”并置顶在游戏上方。若同时把另一款游戏作为前台运行，无法在不使用驱动或进程注入的情况下可靠控制后台原神；本工具不会采用这些高风险方式。

## 运行状态标识

- 绿色“原神已激活 · 输入可执行”：已检测到原神、权限正常，并且原神位于前台。
- 黄色“原神已运行 · 输入已暂停”：游戏已启动，但浏览器或其他窗口当前拥有输入焦点。
- 红色“权限不足”：退出当前助手，重新启动新版并在 Windows 提示中选择“是”。
- 灰色“未检测到原神”：请先启动游戏。

## 使用方法

1. 免安装包中直接双击 `把你砌进神像里.exe`；源码目录也可双击 `启动剧情助手.bat`。
2. Windows 显示管理员权限确认时选择“是”。原神自身使用较高权限运行，助手需要相同权限才能正常发送键鼠输入。
3. 在界面点击功能按钮，或直接按全局快捷键；助手会尝试自动恢复并切换到原神。
4. 使用以下全局热键：

   - 默认 `F6`：开始/停止连续按动作键（默认 `F`）
   - 默认 `F7`：开始/停止连续点击鼠标左键
   - 默认 `F8`：开始/停止长按动作键（默认 `W`）
   - 默认 `F12`：立即停止全部功能

前三项是互相独立的开关，可以同时开启。例如先按 `F8` 长按 `W`，再按 `F7` 连续点击左键；再次按对应快捷键只关闭该项，`F12` 才会全部停止。

## 自定义按键

在“按键设置”标签页中可以修改：

- 连按动作键和长按动作键：支持 `A-Z`、`0-9`、`F1-F24`、`SPACE/空格`、`ENTER/回车`、方向键等。
- 四个全局快捷键：支持单键，也支持 `Ctrl`、`Alt`、`Shift`、`Win` 组合，例如 `Ctrl+Alt+K` 或 `Shift+F8`。
- 点击“应用并保存”后立即重新注册快捷键，并在下次启动时恢复。

“启动功能时自动切换到原神”默认开启。关闭后，工具仍只会在原神位于前台时模拟输入。切换到其他窗口时会暂停并自动释放 `W`；切回游戏后继续当前模式。

## 后台运行

- 点击最小化按钮或关闭主窗口，软件会缩到 Windows 右下角系统托盘并继续运行。
- 双击托盘图标可以恢复主窗口。
- 右键托盘图标可以切换三种模式、全部停止或彻底退出软件。
- 软件只允许启动一个实例；如果重复打开，会提示当前程序已在托盘运行。

## 注意事项

- 剧情选项出现时，连续 `F` 或左键可能直接选择选项，请提前按 `F12`。
- 如果在游戏里没有反应，请先确认状态为绿色，并确保没有旧版助手仍驻留在系统托盘。免安装版会自动请求管理员权限。
- 热键被其他程序占用时，工具会在启动后提示。
- 米哈游可能调整游戏规则或输入行为。请自行确认并遵守当前服务条款；本工具不包含任何规避反作弊的功能。

## 调整速度

窗口中的“连按/连点间隔”默认为 120 毫秒，可设置为 60–600 毫秒。间隔过短可能导致游戏漏输入，通常建议使用 100–200 毫秒。

## 自检（可选）

在此目录打开 PowerShell，运行：

```powershell
py -3 .\genshin_story_helper.pyw --self-test
```

打包后的 exe 不需要安装 Python 或其他软件。以源码方式运行时，需要安装 `requirements-build.txt` 中的托盘与图像组件。

## 重新构建 exe（开发者）

右键 `build.ps1` 并使用 PowerShell 运行，或在当前目录执行：

```powershell
.\build.ps1
```

构建脚本会在项目内创建隔离环境，并将独立程序输出到 `dist\把你砌进神像里.exe`。普通使用者不需要执行此步骤。
